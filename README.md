# 🎮 Tic Tac Toe Game

A modern, responsive, and visually stunning **Tic Tac Toe** game built using vanilla web technologies. It features a premium glassmorphic UI design, neon glowing player symbols, win-state tracking, and a reset system.

## ✨ Features

- 🎨 **Modern Glassmorphic UI:** A beautiful dark-themed design with smooth backdrop blurs and glowing elements.
- ⚡ **Neon Effects:** Distinctive glowing colors for Player X (Cyan) and Player O (Rose Red).
- 🧠 **Win Detection Logic:** Instantly checks for all 8 possible winning combinations after each move.
- 🔒 **Smart Board Locking:** Automatically disables the board once a winner is declared to prevent extra clicks.
- 🔁 **Instant Reset:** A dedicated button to wipe the board, clear states, and start a fresh match.
- 📱 **Fully Responsive:** Perfectly optimized for mobile devices, tablets, and desktops.

## 🛠️ Technologies Used

- **HTML5:** Semantic structures for the grid and controls.
- **CSS3:** Advanced layouts (Grid & Flexbox), glassmorphism effects, and cubic-bezier animations.
- **JavaScript (Vanilla JS):** High-utility DOM manipulation, event listeners, and array-based win pattern calculations.

## 🚀 Getting Started

Follow these steps to run the game locally on your computer:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the project folder:**
   ```bash
   cd tic-tac-toe
   ```

3. **Open the game:**
   Open the `index.html` file in any modern web browser (Chrome, Edge, Safari, etc.). *No extra setups or server environments required!*
